## Web Gamepad Simulation Checklist

- [x] Task A — `web/controls.js` — Inject fake gamepad scaffold at script init time (before DOMContentLoaded, so Emscripten reads it on startup). Create `window.__fakeGamepad` with `id`, `index: 0`, `mapping: "standard"`, `connected: false`, `timestamp: 0`, `axes: [0,0,0,0]`, and `buttons`: array of 16 objects each `{pressed: false, value: 0}`. Override `navigator.getGamepads` to return `[window.__fakeGamepad]` when `connected` is true, else `[]`.

- [x] Task B — `web/controls.js` — Add `attachGamepadButton(btn, index)` helper (parallel to existing `attachButton`). On mousedown / touchstart: set `__fakeGamepad.buttons[index].pressed = true`, `value = 1`, `timestamp = performance.now()`. On mouseup / mouseleave / touchend / touchcancel: reset `pressed = false`, `value = 0`. Use `{ passive: false }` and `e.preventDefault()` on touch events, same as `attachButton`.

- [x] Task C — `web/controls.js` — Add CSS and DOM for the gamepad clusters (initially hidden via `display:none`). Left cluster: same 3×2 grid as keyboard, D-pad buttons ↑↓←→ wired via `attachGamepadButton` to indices 12, 13, 14, 15. Right cluster: 2×2 grid, buttons A (index 0), B (index 1), Y (index 3), Start (index 9). Add CSS class `.cluster-gamepad-right` with `grid-template-columns: repeat(2, 60px); grid-template-rows: repeat(2, 60px); gap: 6px;` and position each button in its grid cell. Also add CSS for a `.btn-toggle` style: smaller than action buttons, neutral background, centred between the clusters.

- [x] Task D — `web/controls.js` — Add the mode toggle button between the two clusters in `#game-controls`. Track `var currentMode = 'keyboard'`. On click: if switching to gamepad, set `__fakeGamepad.connected = true`, `timestamp = performance.now()`, dispatch `new GamepadEvent('gamepadconnected', { gamepad: window.__fakeGamepad })` on `window`, hide keyboard clusters, show gamepad clusters, update toggle label to `🎮`. If switching to keyboard, set `__fakeGamepad.connected = false`, dispatch `new GamepadEvent('gamepaddisconnected', { gamepad: window.__fakeGamepad })` on `window`, hide gamepad clusters, show keyboard clusters, update toggle label to `⌨`. Initial toggle label: `⌨`.

- [x] Task E — `web-template/controls.js` — Mirror all changes from Tasks A–D into the template file so future web builds include gamepad simulation. The template is structurally identical to `web/controls.js`; apply the same additions in the same positions.
